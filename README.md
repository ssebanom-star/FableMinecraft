# Blockworld — 파이썬 3D 복셀 샌드박스 생존 게임

Python + **ursina** 엔진으로 만든 독립적인 블록 기반 생존 게임입니다.
청크 기반 무한 지형, 바이옴, 동굴, 광물, 제작/제련, 몹과 전투, 낮과 밤,
날씨, 저장/불러오기를 지원합니다.

> 특정 상용 게임의 이름/로고/텍스처/사운드/고유 디자인을 사용하지 않으며,
> 모든 블록은 색상 기반의 자체 그래픽으로 렌더링됩니다.

---

## 1. 설치 방법

Python 3.10+ 권장 (3.11 에서 테스트됨)

```bash
pip install -r requirements.txt
```

의존성: `ursina`(내부적으로 panda3d 포함), `numpy`

## 2. 실행 방법

```bash
python main.py
```

시작 메뉴에서 **새 월드**(이름/시드/모드 선택) 또는 **월드 불러오기**를
선택하면 게임이 시작됩니다. 시드가 같으면 항상 같은 월드가 생성됩니다.

## 3. 조작법

| 키 | 동작 |
|---|---|
| W / A / S / D | 이동 |
| 마우스 이동 | 시점 회전 |
| Space | 점프 (물속: 헤엄, 크리에이티브: 상승) |
| Shift | 달리기 (스태미나 소모) |
| Ctrl | 웅크리기 (크리에이티브: 하강) |
| 좌클릭 (유지) | 블록 파괴 / 몹 공격 |
| 우클릭 | 블록 설치 · 상호작용(작업대/화로/상자/문) · 활 발사 |
| 우클릭 (유지) | 음식 섭취 |
| 1 ~ 9 / 휠 | 핫바 슬롯 선택 |
| E | 인벤토리 열기/닫기 (2x2 제작 포함) |
| Q | 선택 아이템 1개 버리기 |
| F | 상호작용 (우클릭과 동일) |
| C | 서바이벌 ↔ 크리에이티브 전환 |
| F3 | 디버그 정보 표시 |
| Esc | 일시정지 메뉴 / 화면 닫기 |

인벤토리 화면에서: 좌클릭 = 집기/놓기/합치기, 우클릭 = 절반 집기/1개 놓기.

## 5. 구현된 기능

- **월드**: 16×16×128 청크, 렌더 거리 내 로드/밖 언로드, 보이는 면만
  합친 청크 메시(불투명/반투명 분리), 변경 청크만 재빌드
- **지형**: 시드 결정론, fBm 노이즈 언덕/산/평야, 3D 노이즈 동굴,
  깊이별 광물 6종, 호수/해변, 나무 3종(참나무/자작/가문비)
- **바이옴 9종**: 평야, 숲, 자작나무 숲, 사막, 설원, 산악, 늪지, 해변, 호수
  (지표 블록/높이/나무·식물 확률/물/몹 스폰이 바이옴별로 다름)
- **블록 56종**: 자연/광물/건축/특수(발광·가시·탄성·미끄럼·폭발) 블록,
  경도/도구 요구/드롭 테이블/광원/충돌 속성
- **아이템 110종**: 블록/자원/도구(등급 4)/무기(검·활)/음식/장비 아이템,
  내구도·채굴속도·연료·제련 속성
- **제작**: 2×2 기본 + 3×3 작업대, 모양(shaped)/자유(shapeless) 레시피
- **화로**: 연료 연소 시간, 제련 진행 바, 결과 슬롯
- **상자**: 27칸 저장, 파일에 내용 저장, 파괴 시 내용물 드롭
- **문/횃불**: 문 열기·닫기(충돌 변경), 횃불 광원(BFS 빛 전파)
- **생존**: 체력/허기/스태미나/산소, 낙하 피해, 익사, 굶주림 피해,
  허기 기반 자연 회복, 사망 시 일부 아이템 드롭 + 리스폰
- **몹 10종**: 수동(돼지·소·양·닭·토끼), 적대(괴인·독거미·해골 사수·
  폭발 덩굴·동굴 몹), 추적/도망/원거리/자폭 AI, 드롭 테이블
- **전투**: 무기 공격력/쿨타임, 넉백, 방어구 감소, 화살 투사체, 폭발 블록 파괴
- **낮과 밤**: 하루 길이 설정, 하늘색/전체 밝기 변화, 밤 적대 몹 증가,
  낮에 불타는 언데드(비 오면 안 탐)
- **날씨 5종**: 맑음/비/눈/안개/폭풍 — 밝기·안개·몹 스폰에 영향
- **저장/불러오기**: 시드, 플레이어, 인벤토리, 변경 블록, 컨테이너,
  시간/날씨, 몹/드롭 상태 (자동 저장 포함)

## 6. 저장 파일 위치

```
saves/<월드이름>/world.json             시드, 시간, 날씨
saves/<월드이름>/player.json            위치, 체력, 허기, 산소, 모드
saves/<월드이름>/inventory.json         인벤토리 + 장비
saves/<월드이름>/containers.json        상자/화로 내용
saves/<월드이름>/modified_blocks.json   변경된 블록
saves/<월드이름>/entities.json          몹 + 드롭 아이템
```

## 7. 설정 변경 방법

- 게임 내: 시작 메뉴 → **설정**, 또는 Esc 일시정지 메뉴에서
  렌더 거리 / 마우스 감도 / FOV 등을 조절
- 파일로: 첫 실행 후 생성되는 `settings.json` 을 직접 수정
  (해상도, 전체화면, 렌더 거리, 시드, 하루 길이, 난이도, 시작 모드,
  최대 FPS, 밝기, 볼륨, 몹 스폰, 드롭 유지 시간 등)

## 8. 성능 관련 주의사항

- 순수 파이썬 + ursina 이므로 **렌더 거리(기본 3)** 가 성능에 가장 큰 영향을
  줍니다. 끊기면 설정에서 1~2로 낮추세요.
- 청크 생성/메시 빌드는 프레임당 예산제(각 1~2개)로 분산되지만,
  새 지역으로 빠르게 이동하면 로딩이 눈에 보일 수 있습니다.
- 최적화 기법: numpy 벡터화 지형 생성, 보이는 면만 메시화, 청크당 1~2개
  엔티티, 몹 AI 업데이트 거리 제한, 드롭 개수 상한, 낮/밤 밝기는 메시
  재빌드 없이 엔티티 틴트로 처리.

## 9. 미구현 / 제한된 기능

- 사운드 없음 (에셋 미포함, 볼륨 설정만 존재)
- 텍스처 없음 (면별 색상 렌더링)
- 물 흐름 시뮬레이션 없음 (정적 물)
- 조명 전파가 청크 경계를 넘지 않음 (경계에서 약간의 밝기 차이 가능)
- 계단/반블록은 단순화된 충돌 사용
- 멀티플레이 없음
- 태양/달 오브젝트 없음 (하늘색 변화로 표현)

## 10. 확장 가능한 기능

- 블록/아이템/레시피/몹은 전부 데이터 정의라 각 파일에 항목만 추가하면 확장됨
- 텍스처 아틀라스 적용 (chunk.py 의 UV 생성 추가)
- 물 흐름/농사/번식/마을 등 시스템 추가
- 조명 전파 청크 경계 지원, 앰비언트 오클루전
- 청크 생성 스레드화로 로딩 히치 제거
